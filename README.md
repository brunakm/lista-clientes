# Lista de Clientes 📋

Projeto desenvolvido como atividade acadêmica com o objetivo de praticar manipulação de dados, formulários e exibição dinâmica de informações utilizando JavaScript.

## 📋 Sobre o Projeto

A aplicação permite cadastrar clientes por meio de um formulário e exibir os registros em uma lista organizada na página.

O projeto foi criado para exercitar conceitos fundamentais de desenvolvimento Front-end, incluindo captura de dados, manipulação do DOM e atualização dinâmica da interface.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades

* Cadastro de clientes
* Exibição dinâmica da lista de clientes
* Atualização da interface em tempo real
* Validação básica de dados
* Interface simples e intuitiva

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/brunakm/lista-clientes.git
```

2. Abra o arquivo `index.html` em qualquer navegador.
